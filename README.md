# Customer Spending Prediction
This project is a web app that predicts how much a customer is likely to spend. I've built it using machine learning to look at different factors, like a customer's age, income, and shopping habits.
## Features
Predicts customer spending amount.
Easy-to-use interface built with Streamlit.
Uses different machine learning models like Random Forest, Decision Tree, and Linear Regression to find the best predictions.
## Tech Stack
Python
scikit-learn
Pandas \& Seaborn
Streamlit
